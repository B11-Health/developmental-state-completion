# Funding Pipeline

This file is intentionally verification-first. Opportunities move to READY only after the official 2026 program page is checked.

|---|---|---|---|---|---|---|
| Pending Lane C authoritative search | RESEARCHING | - | No | No | - | Populate from official sources only |

## Entity facts that must be verified before submission
- Code Gym legal entity name
- current IRS 501(c)(3) status and determination documentation
- EIN
- UEI / SAM.gov status and expiration
- Grants.gov registration
- eRA Commons or other sponsor-specific registrations
- authorized organizational representative
- eligible principal investigator(s)
- indirect-cost treatment / negotiated rate if applicable
- audited financials or required organizational documents

No application should contain guessed values for any of these fields.
