## 1. Code Gym LinkedIn company post

The latest wave of this project is less about making the claim bigger than making the boundary sharper.

- **Optimization:** In the reproducible 128-world simulator bundle, greedy matched the exact optimum on all **17,280 audited rows**. That is an instance result, not a theorem: concrete non-submodularity remains, and frozen counterexamples show greedy can be arbitrarily poor in general.
- **Cross-system reanalysis:** In public *C. elegans* lineage data, nonlinear models showed large held-out gains from ancestral timing beyond a deliberately coarse present-state representation. We still refused to call the preregistered test positive because its calibration power was only **17.5–39%**, below the required promotion standard.
- **Living biology:** Phase 0 is a **conditional GO**. The confirmatory RCOg-V living study is **NO-GO today** while material/transfer, optical-compatibility, burden, and related feasibility gates remain unresolved.
- **Funding:** NSF Mathematical Biology is a **GO for full proposal preparation, not submission**. Institutional submission authority and key Research.gov organization/role gates remain unverified.

The discipline is the result: exact audits where we can, explicit unresolved calls where calibration fails, and NO-GOs where the real-world prerequisites are not yet in hand.
