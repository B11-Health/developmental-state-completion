# Alternative-System Fallback and GO / NO-GO Gates

## Preferred system
Three-class RCOg-V panel: RCOg-V, cuc2-4;RCOg-V, and cyp71-3;RCOg-V (nop2a-5 fallback), each with a functional PIN1:GFP reporter and the Hu dex-inducible ChCUC1:tdTomato system.

## Fallback 1 — exact Hu Col-0 inducible/PIN1 system only
If RCOg-V or suppressor transfer is impractical but the Hu representative lines are available, run a **method-transfer feasibility study**, not the RCO hidden-genotype confirmatory test. Use the published Col-0 PIN1p::PIN1:GFP + ChCUC1p::LhG4:GR;Op::ChCUC1:tdTomato system, matched dex/mock, and a frozen future leaf outcome. This can validate acquisition, blinding, response features, stage matching, burden measurement and history-gain calibration, but it cannot support claims about RCO suppressor discrimination.

## Fallback 2 — stock-centre genetics plus newly built RCO construct
Only if the originating lab confirms that direct RCOg-V seed transfer is impossible but permits reconstruction, consider rebuilding pChRCO::ChRCOg-VENUS from the published design and crossing into publicly obtainable comparator alleles. This is a **new biological system** requiring independent validation of insertion/copy effects and cannot be treated as the Wang lines. It is slower and scientifically weaker for direct replication.

## Fallback 3 — RCO-independent prospective leaf-state test
If neither RCOg-V nor Hu inducible material can be transferred, select a different Arabidopsis perturbation system only after identifying: (a) a present-state baseline, (b) a standardized reversible/acute perturbation, (c) a measurable 24-48 h response, and (d) a later leaf outcome. The claim must be rewritten around that system; no RCO-specific language survives.

## GO / NO-GO gates

### Gate A — legal/material identity
GO only if exact seed/construct identities, holder, transfer permission/MTA path, and recipient eligibility are known. NO-GO if ownership/redistribution is unresolved.

### Gate B — viable three-class genetics
GO only if RCOg-V + cuc2-4 + one post-initiation suppressor can be propagated and unambiguously genotyped. NO-GO if only two classes survive unless the confirmatory claim is prospectively rewritten as binary before data collection.

### Gate C — reporter neutrality and optical separation
GO only if PIN1:GFP is functional without obvious phenotype rescue/distortion and GFP/VENUS/tdTomato channels pass single-color cross-talk QC. NO-GO for pin1-12 with functional PIN1:GFP under the current endpoint. If VENUS is the only optical problem, conditional GO by dropping RCO-VENUS quantitative features while retaining RCOg-V genotype.

### Gate D — induction transfer
GO only if a frozen dex condition produces measurable tdTomato engagement and interpretable PIN1 response in all primary backgrounds without genotype-specific catastrophic failure. Dose/stage/time changes are allowed only in Phase 0 and then frozen.

### Gate E — burden
GO only if active treatment remains below a prespecified injury/growth/developmental-delay limit in all primary backgrounds. NO-GO if response is inseparable from gross stress. Published Hu heat-shock growth measurements do not satisfy this dex gate.

### Gate F — future outcome
GO only if a later same-leaf or rigorously defined sibling/cohort morphology outcome can be collected without treatment/imaging destroying interpretability.

### Gate G — analysis reproducibility
GO only if feature extraction, blinded QC, stage matching, primary proper score, estimators and prediction-file hashing workflow can be frozen before genotype key release.

### Gate H — comparator claim
For the basic M1>M0 information-gain test, comparator is optional. For any claim that ChCUC1 was a specifically superior/optimal intervention, GO only if a biologically credible burden-matched comparator is nominated and validated prospectively. Otherwise that claim is NO-GO.

## Overall B2 decision
- **Phase-0:** GO, conditional on obtaining collaborator confirmation/material pathway.
- **Confirmatory RCOg-V study today:** NO-GO; exact combined materials, transfer rights, optical compatibility and burden are unresolved.
- **Fallback Hu-only feasibility:** conditional GO if representative lines are transferable.
- **Publication/claim escalation:** NO-GO from B2; this lane generates planning artifacts only.
