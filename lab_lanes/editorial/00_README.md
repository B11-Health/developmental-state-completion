## Editorial rule

Public language must never outrun the evidence ledger. Every public item in this package is followed by an internal evidence-status block that separates:

1. **OBSERVED-DATA REANALYSIS** - reanalysis of previously published biological data.
2. **SIMULATOR EVIDENCE** - results established in a constructed or source-rendered simulator.
3. **MATHEMATICAL RESULT** - theorem, counterexample, or standard mathematical identity, with novelty boundaries preserved.
4. **HISTORICAL / PROVENANCE-INCOMPLETE** - historically reported project result whose original supporting artifact chain is missing or not independently recoverable.
5. **PROSPECTIVE LIVING VALIDATION** - proposed wet-lab work that has not yet been completed.

These labels are not interchangeable. A simulator result is not living validation. A historical report is not a current reproducible result. A task-specific predictive pattern is not a universal biological law.

## Narrow novelty statement used throughout

> We are developing and testing a developmental-biology workflow that asks whether a physically measurable present state is sufficient for specified future interventions, using calibrated residual-history prediction as the diagnostic. When it is not sufficient, we represent the remaining joint state-law alternatives as a finite-resolution connected inverse-fiber component and choose perturbations to split that specific residual ambiguity. Each ingredient has strong precedent in predictive-state theory, observability, topology, and experimental design; the candidate contribution is their task-specific integration and prospective biological validation.

Short version:

> The candidate contribution is not a new definition of state or a new topology, but a falsifiable experimental workflow for measuring when a developmental state is predictively sufficient and for choosing perturbations against the specific mechanism ambiguity that remains.
