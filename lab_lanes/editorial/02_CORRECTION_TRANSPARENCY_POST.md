# Correction / transparency post

## Public copy

### We audited our own evidence and downgraded claims we could not fully reproduce

A research project gets more credible when the correction log is as visible as the result log. We have completed an internal replication and provenance pass on several claims that appeared in earlier versions of the developmental-state-completion work.

Two corrections matter most.

**First:** an early FM1 summary used the exact headline pair `0.272 -> 0.643` for a geometry-to-molecular predictive gain. We can reproduce **near-0.64 nonlinear performance** on a traceable late-L1 current-state task, but we cannot reconstruct the exact original `0.272 -> 0.643` pair from an executable cohort/split/target artifact chain that existed with the original prose. The exact historical tuple is therefore **not independently reproduced / provenance-incomplete** and should not be quoted as a replicated result.

**Second:** the original generator/source/output bundle behind the historical **224-world** simulator report was not recovered in the authenticated workspace. The same is true for the named historical topology checkpoint and the original outputs behind the old connected-fiber threshold and perturbation-ranking numbers. Those items remain historical project reports, not current source-validated measurements.

A later source-validation package **does** exist and is reproducible: the separate 128 world/context two-context bundle. It supports a frozen prospective simulator result. It is a different experiment and must not be used as a substitute for the missing 224-world study.

None of these corrections erase the results that are currently reproducible. The late-L1 FM1 screening pattern survives in a narrower, task-specific form. The two-context source-simulator result has a verifiable frozen bundle. The mathematical counterexample showing that greedy connected-ambiguity selection can be arbitrarily bad is reproduced independently. The proposed living-plant experiment remains prospective.

This is the standard we want going forward: **if the source chain is incomplete, the language gets weaker - even when a nearby modern analysis looks similar.** We would rather lose a dramatic number than keep a number we cannot fully defend.
