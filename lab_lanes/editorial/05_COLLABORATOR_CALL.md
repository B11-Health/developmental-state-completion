# Collaborator call

## Public post

### Seeking Arabidopsis collaborators for a falsification-first developmental-state experiment

We are looking for an **Arabidopsis developmental-biology collaborator** to help determine whether a computational result survives contact with a living system.

The question is deliberately narrow. For a specified developmental prediction task, can a physically measurable present state make older measured history predictively redundant? If not, can a designed perturbation expose the missing state/mechanism direction more efficiently than a baseline-only approach and, if a biologically valid burden-matched control can be defined, an equal-cost/random perturbation comparator?

The current evidence base is mixed by design:

- **Observed-data reanalysis:** a direct-source FM1 flower-atlas audit supports a strong task-specific late-L1 screening pattern, while an earlier L1 window is estimator/split sensitive.
- **Simulator evidence:** a frozen two-context source-simulator experiment prospectively recovered hidden signed state in a restricted model.
- **Mathematics:** the target ambiguity refines under added experiments for a monotone metric, but connected-ambiguity reduction is not generally submodular and greedy can fail arbitrarily badly.
- **Historical/provenance-incomplete:** older 224-world/topology/ranking artifacts and the exact historical `0.272 -> 0.643` FM1 tuple are not being used as current replicated evidence.
- **Living validation:** not done yet. That is the point of the collaboration.

The source-audited biological starting point uses published RCOg-V suppressor genetics and a published inducible ChCUC1/PIN1:GFP response interface. The current minimal plan is intentionally conditional: `RCOg-V`, `cuc2-4;RCOg-V`, and one feasible post-initiation suppressor (`cyp71-3` preferred, `nop2a-5` fallback), subject to actual material and crossing feasibility. `pin1-12` is excluded from the primary panel because PIN1 polarity is the proposed response assay.

We specifically need expert input on material transfer/availability, cross compatibility, reporter compatibility, inducible-assay transfer, imaging logistics, biological burden controls, and what constitutes a legitimate equal-cost/random perturbation in this system. We are **not** looking for someone to rubber-stamp a theory. The experiment should be designed so it can fail decisively.

If you work on Arabidopsis leaf development, CUC/PIN1/RCO biology, quantitative live imaging, or perturbation-based developmental inference and this sounds scientifically useful, we would welcome a technical conversation.
