# Source / claim checklist

Run this checklist before any post, description, release note, email, video script, interview answer, or press-page copy leaves draft status.

## Evidence identity

- [ ] Every scientific claim can be assigned to exactly one primary evidence class: observed-data reanalysis, simulator evidence, mathematical result, historical/provenance-incomplete, or prospective living validation.
- [ ] Mixed claims are split into separate sentences rather than blended.
- [ ] Simulator evidence is not described as biological validation.
- [ ] Historical reports are not described as currently reproduced.
- [ ] Prospective biology uses future/proposal language.

## FM1 / observed-data checks

- [ ] If discussing late L1, the task is identified as task/stage/representation specific.
- [ ] No exact conditional-independence or universal Markov claim is made.
- [ ] If discussing the 25 channels, they are described as integrated atlas annotations rather than repeated simultaneous live-cell molecular assays.
- [ ] If discussing an earlier L1 window, estimator/split dependence is acknowledged.
- [ ] If quoting the exact historical `0.272 -> 0.643` pair, it is only in a correction context and labeled not independently reproduced / provenance-incomplete.

Primary source: `CLAIMS_AND_EVIDENCE.md` C1, C2, C13, C15 and R1 checkpoint.

## Simulator checks

- [ ] The 128 world/context two-context source-validation bundle is called a separate later experiment.
- [ ] It is not substituted for the missing historical 224-world study.
- [ ] “Two contexts” is not generalized to universal two-perturbation sufficiency.
- [ ] The five-mask extension is described as new-context/mask generalization for already partially observed laws, not new-law generalization.

Primary source: `CLAIMS_AND_EVIDENCE.md` C17 and source-validation bundle.

## Mathematical checks

- [ ] Refinement claims specify a monotone/product/sup experiment metric.
- [ ] Noise robustness is described as tolerance/threshold interleaving, not same-delta setwise stability.
- [ ] Finite exact separation is not claimed from compactness alone on arbitrary infinite spaces; fixed positive resolution is specified.
- [ ] Greedy connected-ambiguity design is not called near-optimal in general.
- [ ] The source-derived stress case is not described as a greedy failure; greedy matched optimum at budgets 1-5 there despite non-submodularity.
- [ ] Rooted-tree guarantee is limited to the deterministic stated model.
- [ ] Established precedents are named as established rather than claimed as project inventions.

Primary source: `lab_lanes/math/THEOREM_COUNTEREXAMPLE_CHECKPOINT_2026-08-29.md`.

## Provenance checks

- [ ] Historical 224-world generator/source/output is not called recovered.
- [ ] Historical named frozen checkpoints are not called present.
- [ ] Historical connected-fiber threshold/ranking numbers are not presented as current source-validated measurements.
- [ ] Any mention of those results uses “historically reported” and/or “provenance-incomplete.”

Primary source: `lab_lanes/provenance/P1_PROVENANCE_RECOVERY.md`.

## Living-biology checks

- [ ] No statement implies the decisive living-plant perturbation experiment has been performed.
- [ ] Material availability is not assumed.
- [ ] Cross/reporter compatibility is not assumed.
- [ ] The Hu inducible condition is not described as validated in the proposed RCOg-V suppressor backgrounds.
- [ ] No sample size or power claim is invented; confirmatory power awaits pilot variance where required.
- [ ] Designed-perturbation superiority is not claimed before a valid equal-cost/random comparator is defined and tested.

Primary source: `lab_lanes/biology/B1_CHECKPOINT_2026-08-29.md`, `BIOLOGICAL_SOURCE_AUDIT.md`, `PREREGISTRATION_READY_MINIMAL_DESIGN.md`.

## Novelty checks

- [ ] The N1 narrow novelty statement is used or faithfully paraphrased.
- [ ] No “first,” “unprecedented,” “new definition of state,” or “new topology” wording appears.
- [ ] Predictive-state, observability, Reeb/Stein, active-design, fate-prediction, perturbation-response, and cryptic-variation precedents are respected.

Primary source: `lab_lanes/novelty_comms/PUBLIC_NOVELTY_STATEMENT.md` and N1 red-team report.

## Final newsroom test

- [ ] A skeptical scientist could tell which results are data reanalysis, which are simulator results, and which are mathematical.
- [ ] A journalist could not reasonably infer living validation where there is none.
- [ ] Corrections are visible enough that an old headline number cannot be mistaken for a current reproduced result.
- [ ] The strongest sentence in the piece is no stronger than the strongest sentence in `CLAIMS_AND_EVIDENCE.md`.
- [ ] If any source changed after this draft was created, this checklist was rerun against the new source.
