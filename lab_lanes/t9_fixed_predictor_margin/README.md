# T9 Fixed-Predictor Adequacy Margin

T9 derives an exact finite-sample identity for how synthetic outcome injection changes a predictor's squared-error advantage over a baseline. For fixed predictor `p` and baseline `b`, the quadratic injection variance cancels; only `2a<z,p-b>` changes the margin.

This separates mechanical variance inflation from baseline movement and predictor-refitting/domain-generalization effects. It is design algebra only, with no novelty or biological claim.
