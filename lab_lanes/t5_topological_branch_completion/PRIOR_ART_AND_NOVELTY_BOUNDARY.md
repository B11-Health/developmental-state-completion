## T5's potentially useful synthesis
The potentially distinctive contribution is not any single theorem above. It is the explicit pipeline

`local differential invisibility -> fiber connected components -> future-response equivalence -> minimal branch-code requirement -> separating intervention panel -> prospective history-collapse test`.

For developmental-state-completion this synthesis creates a concrete bridge between three kinds of evidence that are usually discussed separately:
1. differential/geometric non-observability;
2. topology of globally disconnected candidate states with identical current measurement;
3. statistical residual-history value and prospective perturbation design.

The empirical prediction is unusually specific: if residual history is acting mainly as a proxy for a hidden topological/future-response branch, then a prospectively measurable branch coordinate should preserve/improve adequate future prediction while reducing the calibrated incremental value of older history.

That prediction can fail, and failure would be informative.

## What requires a deeper literature check before publication
Before any mathematical novelty claim, a specialist search should explicitly cover:
- Reeb-space universal properties and factorization of functions constant on fiber components;
- monotone-light factorization and quotient maps with connected fibers;
- mode/location observability in hybrid systems;
- minimal sufficient refinements and Blackwell/sufficient-statistic comparisons;
- state abstraction/bisimulation under intervention families;
- sensor placement for global distinguishability of disconnected modes.

If an existing result already states the full branch-code/future-response formulation, T5 should be framed purely as an application/synthesis for developmental predictive-state experiments.

## Safe novelty statement
> The present work combines established fiber-component quotients, predictive equivalence, and separating experiment design into an intervention-indexed workflow for diagnosing when residual history may be proxying a presently unmeasured global branch. We do not claim priority for the underlying topological or observability constructions.
