## Required proposal package
Prepare only from verified facts and the current PAPPG/system at submission:
1. Cover Sheet/metadata.
2. Project Summary with labeled Overview, Intellectual Merit, Broader Impacts.
3. Project Description.
4. References Cited.
5. Budget + Budget Justification using documented salary/fringe/F&A only.
6. Facilities, Equipment and Other Resources.
7. Current NSF-compliant biosketch for each senior/key person.
8. Current and Pending (Other) Support for each senior/key person.
9. Collaborators & Other Affiliations and any current personnel documents.
10. Data Management and Sharing Plan.
11. Mentoring Plan only if triggered by the final personnel/budget and current PAPPG.
12. Letters of Collaboration only for real arrangements using compliant commitment language.
13. Subaward package(s) only after institutional agreement.
14. Research-security/disclosure certifications only through the authorized current workflow.
15. Organizational policy/certification support, including COI.

## Critical path
**Gate 0 - institutional:** maintain SAM; verify current SAM reps/certs; obtain documentary legal/nonprofit records; establish Research.gov org registration; establish intended PI affiliation; establish actual AOR and SPO/equivalent authority.

**Gate 1 - team:** freeze PI/co-PI/senior/key personnel; choose collaboration route; obtain real collaborator commitments before describing facilities/materials as available.

**Gate 2 - science:** freeze Summary/Description; freeze surviving theorem claims; freeze computational benchmarks/falsification; narrow biology to executable scope.

**Gate 3 - admin package:** generate current common forms; verified budget; facilities; DMS; subaward docs; final PAPPG/solicitation compliance.

**Gate 4 - red team:** no universal Markovity, priority inflation, living-validation claim before data, guessed registrations/rates, or speculative collaborator commitments. Submission only by an actually authorized AOR.

## Hard no-go conditions
Do not submit while Research.gov organization/PI/AOR routing is unverified; AOR authority is undocumented; legal/nonprofit representations are unsupported; F&A treatment is guessed; personnel disclosures are incomplete; collaborator/material/facility commitments are speculative; MathBio success depends on an unexecuted wet-lab arm; or BIO Core lacks an executable living-system path.
