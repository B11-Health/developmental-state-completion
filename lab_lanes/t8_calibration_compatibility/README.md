# T8 Calibration Compatibility Envelope

T8 gives an audited idealized design envelope for a calibration that must preserve present-only adequacy while making a synthetic omitted-history direction detectable.

Under `E[E|S]=0`, `E[Z|S]=0`, `Z` measurable from `(S,H)`, and the crucial audited condition `E[E|S,H]=0`, an amplitude exists for present threshold `rho` and incremental threshold `delta` iff

`r0 >= rho/(1-delta)`.

When `r0>=rho`, `Delta_max=1-rho/r0`.

T8A showed that without the no-extra-residual-information condition the augmented curve needs an additional `q=Var(E[E|S,H])/B` term. T8 is elementary idealized design algebra, not a theorem about the finite-sample R10/R11/R12 gates and not a novelty claim.
