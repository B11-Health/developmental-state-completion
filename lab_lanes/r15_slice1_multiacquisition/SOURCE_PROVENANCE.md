# R15 Source Provenance

SLICE-1 was published as a 2025 Scientific Data open dataset comprising 50 Tribolium castaneum light-sheet recordings, with up to 301 time points and four directions per specimen. Data are distributed through the SLICE-1 Zenodo community. R15 uses only released `Movie-FQ.TIF` preview stacks plus per-dataset metadata for this pilot.

Official anchors checked 2026-08-30:
- https://doi.org/10.1038/s41597-025-06406-6
- https://zenodo.org/communities/slice-1

Development files downloaded before preregistration: DS0004 and DS0005. Validation preview files DS0007 and DS0035 were not downloaded before this protocol was frozen.
