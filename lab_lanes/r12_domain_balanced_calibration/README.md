# R12 Domain-Balanced Calibration

R12 asks whether R10B calibration failure was partly an artifact of injecting unequal synthetic residual-history amplitudes across the two acquisitions.

**Primary result:** within-acquisition balancing alone leaves joint success unchanged at 16/30, with the same successful directions as R10B.

**Secondary planning diagnostic:** acquisition-specific Ridge residualization against S preserves S-only adequacy in 30/30 and yields 18/30 joint success, still below the frozen 24/30 requirement. This is outcome-blind but transductive/acquisition-conditioned and does not establish literal S-unpredictability.

R12 is calibration-design work only. It does not upgrade the biological history conclusion.
