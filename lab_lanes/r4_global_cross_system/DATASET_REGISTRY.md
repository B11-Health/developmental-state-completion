# R4 Global Cross-System Developmental Dataset Registry

Date: 2026-08-30

## Purpose and audit convention

This registry is a screening registry for public developmental datasets in which a defensible history/present/future (H/S/Y) construction **might** be possible. It is not a claim that every entry already contains true longitudinal H/S/Y measurements. Cross-sectional time courses, pseudotime, trajectory labels, reporter enrichment, or perturbation labels are explicitly marked as proxies. A dataset is not promoted merely because it is large.

Verification tiers: **A** = accession/public release and key design facts checked against an official repository or primary-lab/primary-paper page in the isolated research browser; **B** = accession/publication identity checked, but some sample-size/design details remain publication-reported rather than independently enumerated in R4. GEO/ArrayExpress public records are archival access; repository terms govern reuse and no broader license is inferred unless explicitly stated.

## Ranking logic

Ranks reward: (1) a released grouping unit that can prevent clone/embryo/pool leakage; (2) a temporal or intervention axis that can support a nontrivial prediction task; (3) public processed data that can be analyzed without account creation; (4) biological independence from the already-used LARRY and *C. elegans* systems; and (5) tractable compute. They penalize pseudotime circularity, absence of replicate IDs, huge-only releases, and targets derived from the same transcriptome used as S.

## Explicit exclusion rule

A cross-sectional atlas with only a pseudotime coordinate is **not** counted as evidence of history dependence or history screening-off. It remains useful as a methods stress test or trajectory-proxy dataset, but any H/S/Y claim must say “proxy/reconstructed” and must not be translated into a mechanistic Markov/non-Markov statement.
