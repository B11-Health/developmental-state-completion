## Stop / downgrade rules
- No released grouping unit -> analysis may be exploratory but cannot be promoted as leakage-safe.
- Y computed directly from S using the same algorithm -> label as algorithmic self-prediction, not developmental evidence.
- Cross-sectional cells without lineage link -> no literal history/future language.
- Calibration below declared sensitivity -> unresolved even if observed gain is large.
- One estimator only -> no robust promotion.
- Account, controlled access, researcher contact, unpublished material, or ambiguous redistribution rights -> stop and leave queued.
